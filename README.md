# everyphotohasastory.com

Marketing website for Phoenix Photo Archive, served by GitHub Pages at https://everyphotohasastory.com.

- `index.html` is the home page; `privacy/` and `terms/` are the legal pages.
- The feedback form link is set in `FEEDBACK_URL` near the bottom of `index.html`.
- Install buttons link to the app's install guide at https://dkrussow.github.io/phoenix-recorder/install/.
- `CNAME` holds the custom domain. Do not delete it.
